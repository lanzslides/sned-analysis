# data/exports/

Final output tables, named by research question (`qN_*`). Not stored in this repository (see [../README.md](../README.md)).

| File | Relevance |
| --- | --- |
| q1_muni_level_disability_profile.csv | Per municipality: enrollment, diagnosed and manifestation learners, prevalence, and top categories (Q1) |
| q2_diagnosed_share_by_grade_region.csv | Diagnosed vs. manifestation counts and diagnosed share, by grade level and region (Q2) |
| q2_diagnosed_share_by_province.csv | Diagnosed vs. manifestation counts and diagnosed share, by province (Q2) |
| q3_div_elementary_current_ratio_full.csv | Elementary learners per filled SNED teaching item, by division, with the ratio if fully staffed (Q3) |
| q3_div_jhs_current_ratio_full.csv | JHS learners per filled SNED teaching item, by division, with the ratio if fully staffed (Q3) |
| q3_muni_facility_ratio_inclusive_full.csv | Learners per facility by municipality, counting ILRCs, SPED Centers, and SNED-implementing schools (Q3) |
| q3_muni_facility_ratio_strict_full.csv | Learners per facility by municipality, counting only ILRCs and SPED Centers (Q3) |
| q4_facility_profile_full.csv | Per facility: learner counts and disability profile of the host school (Q4) |
| q4_host_satellite_pairs_3km.csv | Each facility paired with the schools within 3 km, with road and straight-line distances (Q4) |
| q4_sned_desert_municipalities.csv | Municipalities ranked by learners enrolled in schools with no facility within 3 km (Q4) |
| q5_lq_diagnosed_categories.csv | Location quotients of diagnosed disability categories by region and income class (Q5) |
| q5_lq_manifestation_categories.csv | Location quotients of manifestation categories by region and income class (Q5) |
| q6_disadvantage_index_by_municipality.csv | Municipal priority score from the Q6 criteria (a–e), with income class (Q6) |
